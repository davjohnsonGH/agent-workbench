# Agent Workbench

Agent Workbench is a workspace for coordinating AI agents across the software
development lifecycle.

The project begins as a frontend-focused application and will evolve into a
full-stack, multi-agent system with orchestration, retrieval, evaluation,
observability, and production infrastructure.

## Status

Early development.

## Development

### Requirements

- Node.js 24+
- npm 11+

### Setup

npm install
npm run dev

### Quality Checks

npm run format:check
npm run lint
npm run check-types
npm run test:run
npm run build
